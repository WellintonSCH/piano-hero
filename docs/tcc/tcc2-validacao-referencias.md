# TCC2 – Validação das referências e banco de ideias

Arquivo de trabalho entre duas IAs.
- A IA de leitura recebe o PDF de uma fonte e preenche o bloco dessa fonte.
- Depois, o arquivo preenchido volta para a revisão do texto do TCC.

Ordem de trabalho:
1. Parte 1, validar o que já está no TCC.
2. Parte 2, banco de ideias para fortalecer o texto depois.

---

## Instruções para a IA de leitura

Você vai receber o PDF de um artigo e o bloco correspondente deste arquivo.

1. Responda **apenas** com base no PDF enviado. Não use conhecimento próprio e não deduza.
2. Para cada pergunta, traga:
   - o **trecho literal** do PDF, no idioma original e entre aspas;
   - a **página** do PDF;
   - **uma linha** em português explicando o que o trecho mostra.
3. Se não encontrar, escreva `NÃO ENCONTRADO`. Não preencha com algo parecido.
4. Preencha o **Veredito** de cada afirmação com uma destas opções:
   - `CONFIRMA`: a fonte diz isso;
   - `CONFIRMA EM PARTE`: diz algo parecido; explique a diferença;
   - `NÃO CONFIRMA`: a fonte não diz isso ou diz o contrário.
5. Confira os **dados bibliográficos** (autores, ano, título, revista, volume, número, páginas, DOI) e aponte qualquer diferença.
6. Em **Outros usos**, anote trechos do PDF que sirvam para outras partes do TCC. Use a lista de seções abaixo. Máximo de 5 itens, cada um com trecho, página e seção sugerida.
7. Mantenha o formato do bloco. Só preencha os campos que estão vazios.

### Sobre o TCC

Piano Hero é um jogo de ritmo para piano que roda no navegador. É gratuito, tem código aberto e aceita piano digital (MIDI), teclado do computador e toque na tela. Foi feito para iniciantes que praticam sozinhos.

- 2.6 Tecnologias web (Web MIDI, Web Audio)
- 3.1 Ferramentas comerciais

  - 4.9 Introdução guiada ao teclado
